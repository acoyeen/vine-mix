VINEMIX INSTALLATION HELP

First time here?
  Keep both missing-driver checkboxes selected to enable VineMix's Virtual
  input and Virtual output. VB-CABLE is required for Virtual input; a compatible
  VAC driver is required for Virtual output, and VAC Lite is included.
  Existing drivers are retained. Read and accept the selected drivers' terms.
  If you only need physical microphone/headphone routing, you can clear both
  boxes. You can run Setup again to add a missing driver later.
  After installation, open VineMix, choose your microphone on Physical input,
  then choose headphones on Listening output. New outputs start muted; turn up
  and unmute only when you are ready to listen quietly.

Virtual Desktop microphone
  Connect your headset in Virtual Desktop and enable Microphone passthrough.
  Check Windows Settings > System > Sound > Input first. If its microphone is
  listed there, select that same recording device on VineMix's Physical input
  node. A virtual microphone can be selected there even though the starter node
  is named Physical input. VB-CABLE and VAC Lite are not prerequisites for it.
  If Windows does not list it, check Virtual Desktop's connection, passthrough
  option and microphone permissions first; installing the bundled cables does
  not create Virtual Desktop's microphone endpoint.

Application folder
  Default: %LOCALAPPDATA%\Programs\VineMix
  Run VineMix.exe, or use the VineMix Start menu shortcut.

Saved workspaces, preferences, backups and logs
  %LOCALAPPDATA%\VineMix
  These files are separate from the application and are retained on upgrade,
  repair and uninstall. Legacy AudioMixer data is retained during copy-only migration.
  Save an extra copy of important workspaces through the application's controls.

Existing portable copies
  All copies share one user account's settings and audio engine identity.
  Setup leaves a running copy in another folder alone. Choose Quit VineMix in
  its tray menu before opening the installed copy. Closing its window only
  hides it to the tray. Do not manually run two engines against the same files.

Virtual audio drivers
  Missing drivers are selected by default for these features:
  - VB-CABLE: route other applications' playback into VineMix's Virtual input.
    Running app capture is another way to receive one application's audio.
  - VAC Lite: send VineMix's Virtual output to a recording/microphone app.
    Select the corresponding VAC recording device as that app's microphone.
  Setup checks installed device and driver-package identity, including disabled
  devices. Existing packages are kept; their names/settings are not reset.
  When you select a missing driver, the next page shows separate vendor terms.
  Driver installation requires your consent and administrator approval.
  VAC Lite installs first, then VB-CABLE. If a vendor window asks for a restart,
  finish VineMix Setup before restarting. VB-CABLE requires a restart; VAC
  normally works immediately, but may request a restart in some cases.
  Cancelling a driver leaves VineMix installed; run Setup to retry.

  An installed but unavailable driver may need enabling, a restart or repair.
  Setup does not reinstall it automatically. Review Windows sound settings,
  Device Manager and the vendor instructions. Check Windows microphone access
  if recording endpoints are inaccessible. Other Windows recording devices can
  be selected on an input node; Setup only bundles the two named driver packages.

Upgrade and repair
  Run a newer installer and use the existing installation folder. Save your work
  and quit a copy running from that folder first. Setup will not force it closed.
  Running the same version again repairs its application files. Downgrading an
  installation marked as a newer version is blocked. Application-only upgrades
  leave shared audio drivers and your saved device selections in place.

Uninstall
  Use Windows Settings > Apps > Installed apps > VineMix > Uninstall, or the
  Start menu uninstall shortcut. Quit the installed copy first. Uninstall removes
  installed application files and shortcuts, retaining saved workspaces and all
  shared audio drivers. If this installed copy owns its start-at-login entry,
  that entry is removed. Other copies' startup entries are retained.

Security and notices
  The current development installer and VineMix executables are unsigned.
  Driver vendor signatures are verified during package preparation. They do not
  sign VineMix or imply vendor endorsement. Read TERMS.txt, THIRD_PARTY_NOTICES.md
  and the licences directory for the separate component terms.

Unattended application-only deployment
  Setup requires explicit /ACCEPTTERMS=1 for /SILENT or /VERYSILENT runs.
  Specify /DRIVERS=none. Driver installs are interactive only. /NORESTART prevents
  an automatic restart. Silent setup does not launch VineMix.
