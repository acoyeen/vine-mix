# VineMix public website audit

18 November 2026 · Public release 0.6.0

**Visitors can get the correct Windows package.** All 32 distinct link destinations across Home, Credits and Attribution responded successfully. Both executable downloads matched their checksums and signed release metadata. The biggest improvements concern the mobile first visit, control over the opening animation and release selection when GitHub returns older data.

The audit covered the public site and an isolated build of public main at `48cb9eca03e3072365f217d8d2ba2ec41a7f824c`. The working checkout pointed to an earlier 0.5.0 Beta revision. Of 86 expected public files, 83 matched the public main Git blobs byte for byte. The differences in the three HTML pages were explained by Cloudflare adding its analytics script during delivery. [Public source reviewed](https://github.com/acoyeen/vine-mix/tree/48cb9eca03e3072365f217d8d2ba2ec41a7f824c/website-redesign) · [Live website](https://vinemix.app/) · [Current release](https://github.com/acoyeen/vine-mix/releases/tag/v0.6.0)

## Findings in priority order

| Priority | Finding and evidence | Change and acceptance check |
| --- | --- | --- |
| High | **The opening makes the visitor wait for an explanation.** The product description is a screen-reader-only heading. Sighted visitors get the logo and Download while the animated copy presents one word at a time at 350 words per minute. With reduced motion, the logo stays and the description is still visually hidden. | Show one persistent sentence beside Download, such as “A visual audio mixer for Windows 11. Choose what you hear and what your apps receive.” Keep it visible at 320 px, with JavaScript disabled and under reduced motion. |
| High | **Visitors cannot pause the rotating words on the page.** The reader changes automatically alongside active navigation and Download. The operating-system motion preference works, but the opening has no keyboard or pointer control for visitors who need to stop the words while reading. | Offer a persistent, keyboard-operable pause or static-view control, or use stationary copy. Verify that stopping the words lasts after focus moves to Download. [Issue 060](../docs/KNOWN_ISSUES.md#issue-060) · [W3C guidance on automatically changing information](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) |
| High | **Mobile loading spends much of its budget below the fold.** Across three cold simulated mobile runs, median largest contentful paint was 3.55 s. A representative run transferred 753 KiB before scrolling, including 332 KiB of fonts and 311 KiB of images. All four fonts are preloaded. The seven-node pipeline requests its artwork on initialization. Lighthouse estimated 270 KiB of mobile image savings. | First defer pipeline artwork until it approaches the viewport, retaining its pre-sized shell. Serve appropriately sized node images and test WOFF2 versions of the three static fonts. Rerun three cold mobile profiles, compare request bytes and LCP, and check font visibility and diagram layout. |
| Medium | **An older release feed can replace the verified download offered by the site.** In an isolated replay, the 0.6.0 page received only the genuine 0.5.0 Beta release record. Its controller switched the installer to 0.5.0 Beta and displayed “Latest Release.” The live feed returned the correct 0.6.0. | Establish the saved and last verified versions as a floor for routine discovery. Test older, incomplete, current and newer feeds. Keep an intentional release withdrawal explicit. [Issue 056](../docs/KNOWN_ISSUES.md#issue-056) |
| Medium | **The driver links have different visible and spoken labels.** Both “VB-CABLE ZIP” and “VAC Lite ZIP” were flagged. The latter expands VAC into “Virtual Audio Cable” in its accessible name, so the visible command is absent. | Start each accessible name with the exact visible words. Append the publisher if useful. Repeat the label-in-name check and test the visible command with speech input. [Issue 057](../docs/KNOWN_ISSUES.md#issue-057) · [W3C label guidance](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html) |
| Medium | **Sharing the homepage describes an obsolete release channel.** The Open Graph description says “An open-source beta for Windows 11 x64.” GitHub marks 0.6.0 as a regular release. There is also no Open Graph image. | Use evergreen product copy or derive channel wording from the release record. Supply an appropriate share image and verify the resulting preview independently of the page title. [Issue 058](../docs/KNOWN_ISSUES.md#issue-058) |
| Medium | **A standalone user can download a driver without knowing whether they need it.** The panel says “Install drivers separately” and offers two ZIPs. The FAQ explains that a microphone-to-headphones route needs neither, and the licence linked from Credits limits VAC Lite to private home use unconnected with income. This matters to the streamers the site addresses. | Label each link by route and put the optional-driver explanation and a direct vendor terms link beside the choices. Test whether a new user can choose correctly for headphones, an app input and monetized streaming without hunting through Credits. [Vendor terms](https://vac.muzychenko.net/en/license.txt) · [Installation guide](https://github.com/acoyeen/vine-mix/blob/v0.6.0/docs/INSTALLATION_AND_UPDATES.md) |
| Low | **A mistyped or retired URL leads to a blank page.** An anonymous HTML request for a missing page returned HTTP 404 and a zero-byte body. | Keep the 404 status and serve a small page with Home, Downloads and Documentation links. Test it on the canonical domain and through a redirect alias. [Issue 059](../docs/KNOWN_ISSUES.md#issue-059) |

## Performance and discoverability

Lighthouse 12.8.2 ran against the live site in Chrome. The mobile profile used a 412 × 823 viewport, 4× simulated CPU slowdown and 150 ms simulated network round-trip time. Mobile homepage results below are medians of three runs. Other pages and the desktop homepage each had one run.

| Page and profile | Performance / 100 | First contentful paint | Largest contentful paint | Total blocking time | Layout shift |
| --- | ---: | ---: | ---: | ---: | ---: |
| Home, mobile | 82 (76–82) | 1.61 s | 3.55 s (3.53–3.88) | 357 ms (329–472) | 0 |
| Home, desktop | 98 | 0.52 s | 1.09 s | 0 ms | 0 |
| Credits, mobile | 100 | 0.85 s | 0.85 s | 12 ms | 0 |
| Attribution, mobile | 100 | 0.89 s | 0.89 s | 0 ms | 0 |

The mobile LCP element in all three runs was the small “Scroll for more” text. The number measures that paint and does not tell us when a visitor understands the product. The four fonts and pipeline images are measurable download costs. Their individual contributions to elapsed time still need before-and-after testing. First-party responses required browser revalidation. Fingerprinted static assets could use longer caching while HTML and release selection stay fresh.

All three pages scored 100 on Lighthouse’s weighted Accessibility and Best Practices checks. The unscored driver-label finding and manual motion review still matter. Home and Attribution scored 100 for SEO. Credits scored 91 and lacks a meta description. The homepage has a canonical URL, title and description. The sitemap contains Home and Attribution, the robots file points to it, and the documented aliases redirect permanently while preserving the sample path and query. If Credits should appear in search, give it a description and include its canonical URL in the sitemap.

Real-user INP and site-wide Core Web Vitals remain unverified. The public PageSpeed service returned HTTP 429. Total blocking time above is a lab measurement. A field assessment needs the 75th percentile of actual visits, segmented by device. [Google’s Web Vitals measurement guidance](https://web.dev/articles/vitals)

## Release integrity, privacy and operations

- **Packages.** Setup was 15,510,339 bytes and Standalone was 19,501,056 bytes. Each complete download matched its published SHA-256 checksum. The RSA-PSS/SHA-256 signature on the 0.6.0 update manifest verified against the project’s public trust key. Both signed sizes and hashes also matched the retrieved files. The audit stopped at file verification. [Release files](https://github.com/acoyeen/vine-mix/releases/tag/v0.6.0)
- **Public delivery.** All 86 public output files returned HTTP 200 and the expected MIME-sniffing, referrer and anti-framing protections. The private header configuration path returned 404. HTTP on the primary domain and HTTPS on the three alternative hosts returned 301 to the canonical HTTPS address with the test path and query intact. The homepage response did not include an enforcing Content Security Policy. A report-only trial should account for the inline startup code, pipeline styles, GitHub API and analytics before enforcement.
- **Browser data.** The live trace fetched a Cloudflare Web Analytics script and received HTTP 204 from the same-origin metrics endpoint. The homepage also contacted GitHub for release discovery, which the controller repeats every five minutes while visible. The public audio-processing statement concerns the desktop app. A concise website privacy note could identify these browser requests and their purpose. The source review found no account or form flow and no first-party cookie or local-storage calls in the reviewed website JavaScript. The host analytics service’s internal retention and configuration were outside the observation. [Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/)
- **Release trust and fallback.** Discovery validates the repository, tag-specific asset URLs, expected filenames and nonempty sizes before changing the links together. Existing tests exercised offline, incomplete-release and reconnect behavior. The page tracks prereleases as well as stable releases, so a future higher-numbered prerelease can become the recommended download. Decide and document the desired channel now that 0.6.0 is stable. Application update verification and website selection are separate steps.
- **Maintainability.** A clean isolated build succeeded, followed by all ten offline suites and seven Edge browser scenarios. The browser suite exercised six viewport configurations, keyboard and pointer FAQ use, navigation focus, no JavaScript, reduced motion, forced colours, failed WebGL, failed artwork and release discovery. The public source builds without project package dependencies. Add the stale-feed replay and share-description check to the release checks. Compare served HTML semantically as well as recording hashes, since the hosting layer injects a script.

## Coverage limits and retest order

Live interaction checks used a Chromium-based desktop browser with responsive viewports. Page width matched the available content width at 320, 390, 768 and 1440 px. These checks establish reflow on that engine. Physical phones, Safari/WebKit, Firefox, real assistive-technology speech output and voice commands remain unverified. The managed security scanner timed out during startup. The security observations above come from delivered headers, browser requests, public source and package verification. Authenticated hosting settings, infrastructure penetration testing, analytics account data, search indexing and installation on a personal machine were outside this audit.

1. Retest the first screen and motion control with keyboard, reduced motion and a first-time visitor on a phone.
2. Compare cold mobile network waterfalls after changing pipeline loading and font delivery. Check a real iPhone and Android device and preserve the measured zero layout shift.
3. Exercise stale, offline and current release feeds. Recheck driver names using speech input, the actual share preview and recovery from a missing URL.

## Published fixes and retest · 19 November 2026

The production website now starts with a stationary wordmark, a visible product
description and an optional Play animation control. Pausing remains effective
after focus moves. Reduced motion and no JavaScript retain the description and
download link. The page defers the pipeline until it is near the viewport,
selects artwork by display size, uses compact IBM WOFF2 fonts and loads its
homepage styles together.

The download controller keeps a saved or verified version as its lower bound.
A stable page features stable releases. The download panel explains each
driver's purpose and usage terms. Its accessible names begin with the visible
ZIP labels. Share metadata uses evergreen wording and a 1200 × 630 JPEG.
Credits has a description, a canonical URL, a sitemap entry and a website
privacy section. A missing page now keeps HTTP 404 and offers recovery links.
The served site enforces a Content Security Policy and uses immutable caching
for content-addressed fonts.
