# Changelog

## 0.3.0-beta.1 — 22 October 2026

Packages built on 21 October 2026; release history published on 22 October 2026.

- Introduce the VineMix product identity and copyable About build information.
- Start new workspaces with a physical input connected to virtual and listening
  outputs, explicit physical assignments and both outputs muted.
- Add explicit workspace recovery and restartable migration preserving originals.
- Coordinate installed and standalone copies around one workspace and session.
- Offer a self-contained standalone EXE and a normal Windows Setup with optional
  vendor audio drivers.
- Add beginner installation, routing, recovery and reporting guidance.

[Downloads, exact checksums, verification and known issues](docs/releases/0.3.0-beta.1.md).
