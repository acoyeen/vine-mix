Beta 6 brings the implemented interface refinements, monochrome branding and

## Changes

- Organize selected nodes into named visual groups with **Ctrl+G** or the
  right-click menu. Frames automatically fit their members, move all members
  when their heading is dragged, offer seven preset colors, and keep readable
  titles down to 30% zoom. Rename by double-clicking the heading or pressing
  **F2**. **Ungroup (keep nodes)** removes only the frame. Groups support
  Undo/Redo, saved interface settings and complete-group copying, without
  adding audio inputs, outputs or processing.
- Add **Settings → Show action notifications**, on by default. Turning it off
  immediately hides routine timed footer messages, while errors, save status and
  Activity remain available. The choice persists across launches.
- Apply a valid precise numeric edit once when clicking away from its field,
  retaining all entered precision. Invalid text remains visible with an outline
  and accessible “Not applied” feedback. Right-click offers **Apply value** and
  **Cancel edit** alongside text commands. Enter, Tab, Shift+Tab and Escape keep
  their apply/cancel behavior. Unchanged refreshes preserve drafts; model changes,
  deliberate dial adjustments and controls leaving use discard obsolete drafts.
- Align the Settings search placeholder with the actual insertion caret and
  typed text across display scaling, preserving field dimensions and existing
  search behavior.
- Give **What's New**, **About VineMix** and **Updates** consistent compact,
  centred information windows. A clear Close action, Escape or clicking back
  on the workspace dismisses them. Their positions stay fixed, and an update
  installation in progress retains its close protection.
- Centre the node count beneath the logo. Group Settings items by purpose using
  the existing separator style: workspace controls, audio tools, app preferences,
  then Help, What's new? and About. Activity sits beside Find node; Quit stays
  separate at the bottom. Search remains at the top.
- Match the app identity to the website's monochrome logo. Use brighter,
  slightly larger soft-white Windows icons with transparent margins for the
  application, taskbar, tray and inherited shortcuts/installer identity.
  In-app branding follows the live text colour, including high contrast.
- Clarify that Virtual input needs VB-CABLE and Virtual output needs a
  compatible VAC driver, with VAC Lite bundled. Interactive Setup selects
  missing eligible drivers by default and preserves selections the user clears.
  Existing drivers are retained. Selected drivers still require explicit
  acceptance of their terms; VAC Lite runs before VB-CABLE, with instructions
  to finish VineMix Setup before restarting Windows.

Physical microphone, headphone and Virtual Desktop microphone routing continue
to work without installing these virtual-route drivers. Vendor installers retain
their own windows, elevation and terms. VAC Lite's private-home, non-income use
restriction remains separate from VineMix's MIT licence.

## Verification status

The initial Beta 6 detached WPF run passed **13,356 checks with 268 renders and
zero binding errors**, including numeric-entry, search, branding and the new
release highlights. All **17 native offline suites** passed. The Installed-mode
production build, release metadata and inert delivered-executable smoke check
passed. Local activation/recovery regressions also passed. The approved live
transition succeeded: matching Beta 6 app/engine binaries reopened through the
Windows shortcut, retained saved workspace/preferences and recovered previously
running audio paths. Exact source/binary identities and the remaining Setup
bookkeeping distinction are tracked in
[the development record](../BETA6_DEVELOPMENT.md). See
[known issues](../KNOWN_ISSUES.md#issue-004),
[search alignment](../KNOWN_ISSUES.md#issue-001) and
[branding refinement](../TWEAKS.md#tweak-013) for the exact scope and limits.

The later named-group integration passed **13,491 detached checks with 272
renders and zero binding errors**, plus isolated mouse/keyboard checks of
grouping, renaming, preset colors, shared and individual movement, and titles
at 30% zoom. Its guarded interface-only installation preserved the running
engine and saved settings/preferences. See the
[group integration record](../BETA6_DEVELOPMENT.md#named-organizational-groups--28-october-2026)
for the matching source/binary identities, persistence/conflict checks and scope.

The subsequent group and node-stacking refinement passed **13,526 detached
checks with 273 renders and zero binding errors**. Group backgrounds are
brighter and directly selectable/draggable, hover help is shorter, and the
most recently selected or dragged nodes stay in front during the session.
Guarded local integration preserved the original running engine and current
saved workspace/preferences. Real pointer verification of this refinement
was not completed. See the
[refinement integration record](../BETA6_DEVELOPMENT.md#group-refinements-and-node-stacking--28-october-2026)
for identities and verification limits.

The earlier unpublished Setup candidate passed 215 isolated checks, including
driver defaults, explicit consent, preserved deselections, ordered dispatch and
restart policy. Those fixtures did not run the vendor installers. See
[driver setup verification](../TWEAKS.md#tweak-014).

These results identify development candidates and do not qualify the final
Beta 6 packages. Final installer/standalone qualification, matching source,
checksums, signed update metadata and delivered update/recovery tests remain
release work. Native pointer/VR and menu-focus timing, the installed
search caret, actual Windows icon appearance, and fresh-machine driver
installation/elevation/cancellation/reboot need their respective live checks.
No completion of those checks is claimed here.

## Release preparation

The canonical version is `0.3.0-beta.6`, with Windows numeric version `0.3.0.7`
and display version **0.3.0 · Beta 6**. Final publication will pair the Windows
installer and standalone EXE with matching source, `SHA256SUMS.txt` and signed
update metadata from one verified source snapshot. Both formats include .NET.
No Beta 6 download links are advertised until publication.

Earlier release tags and downloads remain intact. Beta 6 does not finalize or
replace provisional Beta 2, and local development updates do not replace the
published Beta 5 files. Signing keys, personal diagnostics and recovery backups
remain outside distributed source and packages.
