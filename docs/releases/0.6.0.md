# VineMix 0.6.0

VineMix 0.6 moves the Windows x64 mixer and audio engine to Rust. The
self-contained desktop and standalone launcher use the original VineMix icon.
Keep using your current shortcuts and workspace.

## Update an existing copy

1. In 0.5, open **Settings → Check for updates**. Choose **Download update** when
   0.6 is offered. Audio can keep running while VineMix verifies the download.
2. Wait for **Saved**, then choose **Install and restart** when ready to pause
   audio. VineMix uses the package that matches your current distribution.
3. Reopen your workspace and check the assigned microphone, listening output
   and virtual output before your next call or recording.

## New installations and manual updates

Choose **VineMix-0.6.0-Setup-x64.exe** for an installed app with shortcuts,
or **VineMix-0.6.0-Standalone-x64.exe** for a single launcher. Download from
[the official release list](https://github.com/acoyeen/vine-mix/releases).
The release includes SHA256SUMS.txt and signed update metadata. Virtual
audio drivers retain their own terms and installation requirements.

If 0.5 reports that the audio engine closed its control connection, wait
for **Saved** and choose **Quit VineMix**. Run 0.6 Setup in the existing
installation folder, or replace your standalone launcher at its original path.

Both distributions passed Windows 11 tests for failed-health rollback,
interrupted updates, normal relaunch and assigned virtual audio devices.
Both also discovered and downloaded the signed release anonymously from
GitHub through the original 0.5 interface. Successful **Install and restart**
runs for Setup and standalone reached 0.6 with advancing engine frames and
the exact workspace saved at handoff. Other runs cancelled in 0.5 before
replacement, as described above.

Run the 0.6.0 desktop as your usual Windows user. Elevated sessions can
report a connection-ownership error. The subsequent source correction
explicitly sets the connection owner to the current user.
When interrupted before it could verify the files Setup had installed,
the update worker retained the previous files and requested manual repair.
