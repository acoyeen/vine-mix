# VineMix 0.4.0 Beta

**28 October 2026 · Windows 11 x64 · Beta**

VineMix 0.4.0 Beta brings together the work previously called Beta 6: named
groups, more stereo mixing tools, clearer controls, interface refinements and
offline credits. Future betas advance the version number: small updates use
0.4.1 Beta and larger feature updates use 0.5.0 Beta. The Beta label has no
sequence number.

**Updater correction:** The first 0.4.0 package exposed a process-identification
race that could restore the previous version after a successful installation
and package check. At the maintainer's request, corrected packages retain the
0.4.0 Beta name. If you installed the earlier 0.4.0 package, download Setup again,
choose **Quit VineMix** and run it over the existing installation. The version
number is unchanged, so Check for updates cannot distinguish those two builds.
Use the published checksums to identify the corrected download.

## Changes

- Organize nodes into named groups with Ctrl+G or the selection menu. Colored
  frames fit their members, move them together and support explicit membership,
  Undo/Redo, saving and complete-group copying. Centered names remain readable
  at low zoom; F2 or a double-click renames them. Ungrouping keeps the nodes.
- Selected and dragged nodes stay in front of overlapping nodes. Groups remain
  behind node and cable controls, and moving a group preserves its internal order.
- Add Channel Swap, Stereo Width, Pan, Crossfade, Stereo Combine and Stereo
  Split to the Mixing category. Named sockets survive saving, copying,
  Undo/Redo, rewiring and cable insertion. Crossfade supports Equal power and
  Linear curves; Stereo Combine and Split keep their channel assignments.
- Replace duplicate Volume/Gain controls with one Level dial where they changed
  the same value. Linked control uses a Multiplier, with 100% unchanged and 0%
  silent. Ducking's sidechain socket is labelled Trigger.
- Apply valid precise numeric edits when leaving the field without rounding away
  entered precision. Invalid drafts remain visible. The text menu provides
  Apply value and Cancel edit; Enter, Tab, Shift+Tab and Escape retain their roles.
- Add a persistent Show action notifications preference. Hiding routine timed
  messages retains errors, save status and the Activity record.
- Align the Settings search placeholder, caret and text across display scaling;
  group related Settings actions and keep Quit separate. Center the node count.
- Give About, What's New and Updates consistent compact windows, dismissal and
  update-install protection. Use monochrome branding and brighter Windows icons.
- Add **About VineMix → Credits and licences**, with project credit and the full
  MIT licence, attribution policy and third-party notices available offline.
  The complete notices also accompany installed and standalone packages.
- Clarify virtual-route driver choices in Setup. Missing eligible drivers start
  selected; explicit deselections are retained. Separate consent remains required,
  VAC Lite runs before VB-CABLE, and restart guidance says to finish Setup first.

The cleanup pass also protects in-progress node/group names during Quit and
update preparation, and prevents unsaved interface preferences from being
silently omitted during shutdown. Pan and Crossfade reuse settled coefficients
while preserving per-sample control smoothing.

## Install or upgrade

Choose [Setup](https://github.com/acoyeen/vine-mix/releases/download/v0.4.0-beta/VineMix-0.4.0-beta-Setup-x64.exe)
or the [standalone EXE](https://github.com/acoyeen/vine-mix/releases/download/v0.4.0-beta/VineMix-0.4.0-beta-Standalone-x64.exe).
Both include .NET. Setup installs the app and shortcuts; standalone prepares its
bundled files when opened from Explorer. Workspaces and preferences remain in
the existing VineMix data directory.

For Beta 5, Beta 6 and the earlier 0.4.0 build, a manual upgrade is recommended:
the installed old updater can fail its early process lookup before it receives
this correction. The corrected worker validates new processes through their
retained handles and native image paths. For
Beta 1–4, use the direct manual upgrade: save, choose **Quit VineMix**, then run
0.4.0 Beta Setup over the existing installation without uninstalling. Standalone
users should quit and replace their launcher. No intermediate download is needed.
The earlier updater compatibility limitation remains documented in the
[update investigation](../UPDATE_INVESTIGATION_2026-10-24.md).

Keep working optional drivers unchanged. Physical microphone/headphone and
Virtual Desktop routes do not need the bundled virtual-route drivers. VAC Lite
retains its separate private-home/non-income terms.

The release provides matching source, `SHA256SUMS.txt` and a signed
`VineMix-0.4.0-beta-Updates.json`. Update signatures authenticate package hashes;
VineMix executables are not Windows Authenticode signed.

## Beta limits and verification

See the [0.4.0 qualification record](../RELEASE_0.4.0_QUALIFICATION.md) for the
final source identity, package checks and published download verification.
Synthetic audio, detached interface rendering and isolated installer/update
fixtures do not establish sustained audio reliability on every device.

Fresh-machine vendor-driver installation, elevation, cancellation and reboot;
real pointer/VR interaction; sustained hardware use; and complete delivered
update/rollback transactions on a separate Windows account remain unqualified.
Normal WPF/Windows resizing is retained. Existing accessibility and dense-graph
navigation limitations remain in the [known issues](../KNOWN_ISSUES.md).

## Earlier releases and attribution

Beta 1–5 release posts and tags remain as version history. Their uploaded
attachments are retired after this replacement's downloads and website are
verified; each historical post records the actual removal date. GitHub-generated
source archives remain available from retained tags.

VineMix remains MIT-licensed. Preserve the supplied copyright and permission
notice when redistributing covered material. Visible in-program acknowledgement
is requested by the [attribution policy](../../ATTRIBUTION.md), rather than an
additional MIT condition. Earlier copies retain their original permissions.
