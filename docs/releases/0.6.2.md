# VineMix 0.6.2

The standalone updater now handles a launcher marked **Read-only**, including copies made from optical media. When you approve an update, VineMix verifies the download, keeps the old launcher, installs the new one and checks that the engine is running with your saved workspace.

### Updating from 0.6.0 or 0.6.1

Open **Settings → Check for updates**, then choose **Download update** and **Install and restart**. Save your work first. Audio pauses briefly during restart.

Older standalone versions run their own updater. If the executable is marked **Read-only**, open its **Properties** in File Explorer, clear **Read-only**, and select **Apply** once before updating. If an update has already stopped at the launcher replacement, clear the attribute, reopen the same launcher and select **Yes** when offered recovery. The updater uses the download it already verified.

Both Setup and standalone packages, matching source, checksums and signed update metadata accompany this release.
