# VineMix 0.3.0 · Beta 3

23 October 2026 · Windows 11 x64

Beta 3 establishes a clean development baseline while retaining Beta 2's
streamed and virtual microphone selection, Add Node tooltips, simpler Setup
and signed in-app update support.

## Downloads

- [Windows installer](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.3/VineMix-0.3.0-beta.3-Setup-x64.exe)
- [Standalone EXE](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.3/VineMix-0.3.0-beta.3-Standalone-x64.exe)
- [Checksums, matching source and signed update metadata](https://github.com/acoyeen/vine-mix/releases/tag/v0.3.0-beta.3)

Both packages include .NET. Quit the current app through its tray menu before
running Setup or switching standalone copies. Existing workspace and preferences
are preserved. Beta 1 users need a manual upgrade to gain the updater. Beta 2
and later can use **Settings → Check for updates**; daily checks never download
or install without your choice.

## Changes

- Keep queued edits and undo history after temporary settings-write failures,
  with a visible unsaved warning and a retry once storage is available.
- Remove the resize redraw workaround and all experimental resize labs from
  active source. Window resizing uses the previous WPF frame behavior. This is
  a removal of unsuccessful interventions, not a claim that Windows shaking or
  ghosting has been fixed.
- Reject fractional, negative or wrongly typed configuration revisions and
  non-integer protocol versions before they can change the saved workspace.
- Allow interrupted update rollback to resume when a file already matches its
  verified original bytes, while preserving unfamiliar replacement files.
- Keep completed updates and rollbacks successful when recovery-registration
  cleanup fails. Retain a cleanup receipt and retry only that housekeeping.
- Give private updater files explicit current-user ownership, fixing staging
  rejection when Windows runs the application as administrator. File ownership
  and access checks remain strict.
- Repair the physical-path and private-pipe verification fixtures responsible
  for the earlier GitHub test failures. Add updater and release-preparation
  checks to continuous integration.
- Reconcile release tooling and documentation, retire local test packages from
  the source checkout, and refresh the product links and beta guidance.

## Verification and limitations

Qualification covers 17 native suites (including a retained timing failure and
passing repeat), 12,142 detached desktop checks, 189 isolated Setup checks,
17 standalone-runtime checks, 71 updater-core checks, 97 update-worker checks
and eight release-preparation checks. Package smoke checks use the actual
executables without starting audio or accessing personal settings.

See [current qualification](https://github.com/acoyeen/vine-mix/blob/v0.3.0-beta.3/docs/BETA_TESTING_CURRENT.md) for exact completed
checks and [the audit record](https://github.com/acoyeen/vine-mix/blob/v0.3.0-beta.3/docs/BETA3_AUDIT.md) for the reviewed changes.
Published `SHA256SUMS.txt` identifies the exact downloads. The signed update
envelope is verified against the application's pinned project key.

Windows Authenticode signing is not provided; Windows may show an
unknown-publisher warning. Project update signatures authenticate the download
hashes and are separate from Authenticode.

Actual Virtual Desktop capture/reconnect, physical-display behavior,
clean-machine installation, sleep/resume, eight-hour real-audio use and complete
delivered-app update/rollback scenarios remain unqualified. An earlier reported
unexpected closure remains unresolved. Report any unexpected exit, workspace
reset, device failure or audio problem with the full About version information.

Beta 1 and provisional Beta 2 retain their original downloads and tags.
