# VineMix 0.3.0 · Beta 5

24 October 2026 · Windows 11 x64

Beta 5 repairs the package metadata that made in-app updates restore the previous
version, improves automatic update checks, and simplifies the update window.
It preserves the earlier releases and all unrelated Beta 4 features.

## Downloads

- [Windows installer](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.5/VineMix-0.3.0-beta.5-Setup-x64.exe)
- [Standalone EXE](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.5/VineMix-0.3.0-beta.5-Standalone-x64.exe)
- [Checksums, matching source and signed update metadata](https://github.com/acoyeen/vine-mix/releases/tag/v0.3.0-beta.5)

Both packages include .NET. For an existing Beta 2, 3 or 4 installation, the
recommended recovery is to save your workspace, use **Quit VineMix** in Settings
or the tray, then run **Beta 5 Setup** against the existing installation folder.
Do not uninstall first. Keep working optional drivers unchanged. Reopen VineMix
from its installed shortcut and check that About displays **0.3.0 · Beta 5**.
Closing the window alone leaves the app and audio running.

For a standalone copy, save and quit, replace the old EXE with the Beta 5
standalone EXE, and reopen it. Existing workspace and preferences are preserved.
Keep any recovery folder if the app requests manual repair; do not restore an
older workspace over newer work.

Skipping beta versions is supported. Corrected engine metadata can be accepted
by the unchanged Beta 2 version checker, but a full delivered upgrade through an
older running client remains a separate qualification task. Manual installation
is the recommended recovery route for users already affected by rollback.

## Changes

- Correct the engine's Windows file-version text to the numeric value required
  by existing update workers. Previously, a valid downloaded package could be
  installed, rejected during version validation and rolled back before the new
  app opened. The semantic product version remains visible in About and other
  release information.
- Verify the actual executable version metadata during native builds, installer
  packaging, isolated Setup checks and standalone extraction checks. Regression
  fixtures exercise the real Windows version check and rollback behaviour.
- Repeat automatic checks daily while VineMix stays open and retry unsuccessful
  checks after 15 minutes. Enabling automatic checks schedules a prompt check;
  failed attempts no longer suppress checking for a day. Downloads and installs
  remain explicit choices.
- Use a compact update window with the app's shared theme, installed version,
  clearer status and relevant actions for each stage. Release notes appear when
  available, and the automatic-check preference explains its behaviour.
- Preserve failed Setup exit codes and a private Setup log for diagnosis.
  Earlier installed workers gain these diagnostics only after upgrading.

## Verification and limitations

The final source passed all 17 native suites, 12,905 detached desktop checks with
236 renders and zero binding errors, 74 update-core checks, 111 update-worker
checks, five native metadata fixtures and nine release-preparation checks.
Activation safeguard suites passed 34 and 54 checks. The redesigned update states
and release highlights were visually reviewed, including high contrast.

Both final packages passed inert release smoke checks. All 18 standalone runtime
checks and 167 isolated Setup checks passed. The unchanged original Beta 2 updater
verified the signed Beta 5 manifest, both package hashes and the corrected version
metadata. Installed and standalone packages contain identical engine bytes.

The matching source ZIP includes SOURCE-MANIFEST.json with the exact source commit,
build-input hashes, package identities and sanitized final verification results.
All five release assets were downloaded from GitHub and rehashed before publication.
The pinned-key update signature and
[source checks](https://github.com/acoyeen/vine-mix/actions/runs/40084102531) passed.
Independent [published-release checks](https://github.com/acoyeen/vine-mix/actions/runs/40084918736)
also passed. After publication, the unchanged Beta 2 discovery code anonymously
selects signed Beta 5 from the public feed, with both package hashes matching
the final downloads.
See the [qualification procedure and limits](https://github.com/acoyeen/vine-mix/blob/v0.3.0-beta.5/docs/BETA_TESTING_CURRENT.md)
and [update investigation](https://github.com/acoyeen/vine-mix/blob/v0.3.0-beta.5/docs/UPDATE_INVESTIGATION_2026-10-24.md).

These isolated checks do not establish a complete delivered update, recovery or
interruption scenario on a separate machine. Actual streamed-headset playback
and reconnect, physical-display behaviour, clean-machine installation,
sleep/resume and eight-hour real-audio use remain unqualified. An earlier
unexpected-closure report remains unresolved. Report failures with the full
About version information, omitting personal paths and workspace contents.

The app, helper and Setup are not Windows Authenticode signed. Windows may show
an unknown-publisher warning. Signed project update metadata authenticates the
download hashes and is separate from Authenticode.

Optional virtual drivers retain their separate terms. VAC Lite is restricted to
private-home use without income generation; VineMix's MIT licence does not
expand those rights. Both optional driver boxes start unchecked.

Beta 1, provisional Beta 2, Beta 3 and Beta 4 retain their original tags and
downloads. Beta 5 does not finalize or replace the provisional Beta 2 release.
