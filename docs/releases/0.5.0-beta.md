# VineMix 0.5.0 Beta

An easier canvas to navigate, new creative effects and more flexible audio routing.
For Windows 11 x64. Existing workspaces, device assignments and levels are preserved.

## What's new

- **A ready-connected voice starter:** Microphone → High-pass filter → Denoiser
  → Expander → Compressor, feeding Listening and Virtual outputs. Both start
  muted, with generous spacing between nodes.
- **A clearer canvas:** zoom down to 10%, simple node blocks at low zoom, an
  optional minimap, smoother meter colours and cleaner short cables. Cables blend
  between socket colours and show midpoint dots at full detail; disabled cables
  have no dots.
- **More keyboard control:** follow pipelines with Ctrl+Tab / Ctrl+Shift+Tab,
  nudge or pan with arrows, zoom with Ctrl++ / Ctrl+−, rename one selected node
  or group with F2, and type directly into a focused dial. Tab / Shift+Tab still
  move between controls.
- **Echo and Distortion:** Echo offers Time, a whole-number Repeats control and
  Mix, plus a separate Echo output. Distortion ranges from subtle warmth to
  strong saturation, with Drive, Tone, Mix and Output. All effects share one menu.
- **Flexible effect routing:** Gate and Expander accept an optional Trigger.
  Reverb's Wet and Echo's Echo outputs carry only their effect, independently
  of Mix, and use light-blue audio sockets.
- **Shared output devices:** several output nodes can feed one device with
  independent levels and mute. Duplicated and pasted outputs start muted.
- **Reliability and polish:** preserve Undo/Redo through decimal Level edits,
  update accessible names after renaming, fit Settings within available space,
  and harden process identity checks during restart.

## Install or update

Choose **Setup x64** for an installed app or **Standalone x64** for a single
launcher. Both include .NET. Setup can offer missing optional virtual audio
drivers with separate vendor terms. Physical microphone/headphone routes do not
need those drivers.

Use **Settings → Check for updates** from the corrected 0.4.0 release. For older
betas or the original uncorrected 0.4.0 build, quit VineMix and run the new Setup
over the existing installation, or replace the standalone launcher. Keep your
workspace and existing drivers; no intermediate release is needed.

After using new nodes or ports, keep using 0.5.0 or newer. Older versions cannot
load every 0.5.0 workspace; see [update and recovery guidance](../INSTALLATION_AND_UPDATES.md).

The app and Setup are not Windows Authenticode signed. The attached checksums
and signed update metadata identify these exact downloads. The source archive
matches their committed build inputs.

## Beta limits

- Hardware, long sessions, native accessibility and complete interrupted-update
  recovery still need broader testing; see the [qualification record](../RELEASE_0.5.0_QUALIFICATION.md).
- Distortion is more demanding than most effects; very large Distortion-heavy
  graphs have limited processing margin during routing changes.
- Many RNNoise denoisers can exceed the audio processing budget. The 32-node
  limit describes routing capacity; processing capacity depends on the effects
  and computer. Share a denoised path before branching when appropriate.
- Per-app capture leaves original playback audible. Parallel routes have no
  automatic delay compensation. Denoising adds 20 or 30 ms, including in bypass.
- Shared output nodes add their signals; repeated routes can overload a device.
  Echo at very short times intentionally sounds like a short delay effect.
