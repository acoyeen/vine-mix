# VineMix 0.3.0 · Beta 2

Released 22 October 2026 for Windows 11 x64.

## Downloads

- [Windows installer](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.2/VineMix-0.3.0-beta.2-Setup-x64.exe)
- [Standalone EXE](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.2/VineMix-0.3.0-beta.2-Standalone-x64.exe)
- [Checksums, source and complete release assets](https://github.com/acoyeen/vine-mix/releases/tag/v0.3.0-beta.2)

Both packages include .NET and preserve the saved workspace. Beta 1 users need
this manual upgrade once to gain the in-app updater. Wait for **Saved**, use
**Quit VineMix** from the tray, then run Setup or the new standalone EXE.

## Changes

- **Streamed microphones:** Physical input accepts Windows recording endpoints,
  including streamed and virtual microphones. Network capture devices no longer
  depend on an advanced output visibility option. Hardware confirmation of
  Virtual Desktop microphone passthrough remains a tester check.
- **Simpler Setup:** the app-only route is prominent. Optional driver boxes
  start unchecked; only selected drivers lead to separate consent. An existing
  streamed microphone needs neither bundled virtual cable.
- **Resize redraw:** opaque, clipped chrome and coalesced redraw address stale
  header/footer damage after resizing. Physical-display confirmation remains open.
- **Add Node help:** creation choices and categories have purpose explanations,
  including filtered and disabled choices. Hidden results no longer intercept help.
- **Updates:** Settings and About offer release checking. Daily checks can be
  turned on or off. Download and installation remain separate explicit actions.
  RSA-PSS/SHA-256 signed release metadata binds exact versions, URLs, sizes and
  SHA-256 hashes before a package is accepted.

The updater saves edits, cooperatively stops its matching engine, updates the
app and verifies the reopened workspace. Recovery retains prior app files and
does not restore older settings over current data. Ambiguous or interrupted
installation may require manual repair; see [worker recovery limits](../UPDATE_WORKER.md).

## Verification and known issues

Recorded checks include all 17 native suites across the first run and a
controlled timing repeat, 12,188 detached desktop checks with 215 renders and
zero binding errors, 71 update-core checks, 66 update-worker checks, eight
signing-tool checks, 189 installer checks and 17 runtime checks. Both delivered
EXEs passed their own inert smoke tests. No timing threshold was weakened.

Actual Virtual Desktop capture/reconnect, continuous physical resizing and
display-scale transitions, an interactive driver installation walkthrough,
clean-machine installation, sleep/resume and eight-hour normal audio/UI use
remain unperformed. A complete installed/standalone update and rollback through
the delivered app is also not yet qualified. Component tests and published
signed assets do not establish that complete flow. An earlier unexplained
closure remains unresolved; report any unexpected exit or workspace reset.
