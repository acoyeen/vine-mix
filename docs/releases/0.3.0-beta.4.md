23 October 2026 · Windows 11 x64

Beta 4 adds streamed headset playback, a layout lock and safer quitting, with
clearer save feedback and release highlights available inside the app.

## Downloads

- [Windows installer](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.4/VineMix-0.3.0-beta.4-Setup-x64.exe)
- [Standalone EXE](https://github.com/acoyeen/vine-mix/releases/download/v0.3.0-beta.4/VineMix-0.3.0-beta.4-Standalone-x64.exe)

Both packages include .NET. Use **Quit VineMix** in Settings or the tray before
running Setup or opening a newer standalone copy. Closing the window keeps audio
running. Existing workspace and preferences are preserved. Beta 1 users need a
manual upgrade to gain the updater. Beta 2 and later can use
**Settings → Check for updates**; download and installation remain your choice.

## Changes

- Choose streamed Windows playback devices, including a Virtual Desktop
  headset's playback endpoint, in **Listening output**. Dedicated cable routes
  retain their own nodes, and saved device assignments remain intact.
- Protect node positions and connections with the top-right layout padlock.
  Red and closed means locked; grey and open means unlocked. Sound controls and
  navigation still work. Selection outlines stay hidden while locked, and a
  blocked edit briefly enlarges the padlock. The lock lasts for the session.
- Quit from the bottom of Settings as well as the tray. The final save finishes
  before audio stops. If saving fails, retry, save a complete recovery copy,
  cancel quitting or explicitly quit without saving.
- See **SpeexDSP · 20 ms** and **RNNoise · 30 ms** in the denoiser menu. These
  are node delays, including bypass, rather than total system latency. The
  processing algorithms and saved settings are unchanged.
- Read bundled **What's new?** highlights after an updated startup, once the
  workspace is healthy and ready. They wait while you edit, save or use another
  dialog. Reopen them from Settings above **About VineMix**.
- Find save status in the centre of the footer. Action messages appear for five
  seconds with a thin green countdown bar; **Dismiss** restores save status
  immediately. Reduced motion keeps a static bar with the same dismissal time.
- Use shorter hover help and clearer keyboard focus cues. Clicking a button
  no longer leaves a white underline behind it.

Normal Windows/WPF resizing and the previous beta features remain. This release
does not claim to resolve Windows resize shaking or ghosting.

## Verification and limitations

See the [Beta 4 qualification record](https://github.com/acoyeen/vine-mix/blob/v0.3.0-beta.4/docs/BETA_TESTING_CURRENT.md)
for completed checks and their scope, and the
[project audit](https://github.com/acoyeen/vine-mix/blob/v0.3.0-beta.4/docs/BETA4_AUDIT.md)
for the release review. Synthetic audio, detached controls and isolated updater
fixtures do not establish live hardware reliability or a complete delivered-app
upgrade. `SOURCE-MANIFEST.json` in the source ZIP records the exact build inputs
and final-package verification. `SHA256SUMS.txt` identifies the downloadable
files, and the signed update metadata binds the two executable hashes.

The app, helper and Setup are not Windows Authenticode signed. Windows may show
an unknown-publisher warning. The project update signature authenticates package
hashes and is separate from Authenticode.

Actual Virtual Desktop sound and reconnect, physical-display behavior,
clean-machine installation, sleep/resume, eight-hour real-audio use and complete
delivered-app update/rollback scenarios remain unqualified. An earlier reported
unexpected closure remains unresolved. Report an unexpected exit, workspace
reset, device failure or audio problem with the full About version information.

Setup's optional virtual drivers retain their separate terms. VAC Lite is
restricted to private-home use without income generation; VineMix's MIT licence
does not expand those rights. Existing drivers are preserved, and both optional
driver boxes start unchecked.

Beta 1, provisional Beta 2 and Beta 3 retain their original tags and downloads.
