# Documentation screenshots

The 0.5.0 images were generated on 6 November 2026 from the actual WPF interface,
using the Release verification build's detached render modes. They use silent
example devices and temporary preview models; no personal workspace or audio
hardware was captured.

- `workspace.png`: configured seven-node starter, both outputs muted.
- `first-run.png`: fresh starter with unassigned physical devices and a missing
  optional virtual output driver.
- `echo.png` and `reverb.png`: actual controls and secondary audio outputs.

The workspace images use a 1280 × 800 logical window rendered at 192 DPI.
PNG chunks were inspected for private text and metadata. These images illustrate
the interface; they are not evidence of audible or real-device qualification.

Other images in this folder retain their original, dated documentation context.
